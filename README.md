# Cartas contra la Humanidad (GitHub Pages Edition)

Juego web multijugador P2P diseñado para ejecutarse 100% estático en **GitHub Pages**.

## Características
- **Cero Servidor Backend:** La comunicación entre jugadores se realiza de navegador a navegador usando **PeerJS (WebRTC)**.
- **Sin Instalación (`0` dependencias):** Solo requiere archivos HTML, CSS y JS estáticos.

## Cómo publicar en GitHub Pages
1. Sube los archivos de este proyecto a un repositorio en GitHub.
2. Ve a la pestaña **Settings** > **Pages** de tu repositorio.
3. En **Source**, selecciona `Deploy from a branch` y elige la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Guarda los cambios. En 1-2 minutos GitHub te dará un enlace (ej. `https://tu-usuario.github.io/nombre-repo/`).
5. Comparte ese enlace con tus amigos para jugar.
